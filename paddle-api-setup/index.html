Paddle Sandbox API

Trang này lưu Paddle API key trực tiếp vào D’AUBE Vault rồi tự tìm webhook destination, tạo hoặc tái sử dụng simulation transaction.completed, chạy simulation qua Paddle API và kiểm tra delivery.

API key cần đúng 2 quyền:
• Notification settings → Read
• Simulations → Write

Không cần cấp All Write. Simulations Write tự bao gồm quyền đọc simulation. Nếu muốn payload dùng transaction thật thay vì dữ liệu demo, có thể giữ thêm Transactions → Read.

API key không được gửi vào ChatGPT hoặc commit vào GitHub. Trình duyệt gửi key qua HTTPS thẳng tới D’AUBE Supabase Edge Function; function chỉ lưu key vào Vault sau khi Paddle authentication và permission checks vượt qua.
