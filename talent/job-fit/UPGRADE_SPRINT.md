- Python
- Linux
- APIs / webhooks / OAuth
- Docker
- Kubernetes
- CI/CD
- AWS / Azure / GCP concepts
- Terraform / IaC
- SQL / Postgres
- testing and documentation
- LLM / agents
- observability
- vector/RAG tooling

## D’AUBE position

### Already evidenced publicly
Python, API/webhook integration, OAuth patterns, Linux operations, Docker, Terraform, Kubernetes validation/RBAC, GitHub Actions/CI, QA/evidence, runbooks and bounded AI workflows.

### Evidence gaps to close
OpenTelemetry/Prometheus hands-on proof, pgvector retrieval proof, stateful agent orchestration proof, deeper cloud-provider deployment examples.

## Upgrade rule

Do not add technology merely as a keyword. Each upgrade must produce:

1. runnable or verifiable artifact;
2. failure/negative test;
3. concise architecture note;
4. explicit security/cost boundary;
5. recruiter-readable evidence link.

This keeps the job-search surface aligned with actual delivery capability.
